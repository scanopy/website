This release brings HPE Instant On networks into Scanopy.

## New Features

- Add HPE Instant On cloud portal integration, letting you pull sites, devices, and client details from Instant On into your topology by connecting your portal credentials; the setup screen clearly flags that it relies on an unofficial API that HPE could change at any time.
