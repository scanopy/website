## New Features

- Let account owners request procurement documents (security reviews, compliance paperwork, and more) from a dedicated card in billing, with the request delivered straight to our team by email.

  ![Billing tab showing the procurement documents request card with selectable document types](/changelog/v0.17.18/procurement-request-card.png)

- Add per-view sort order inside containers, including sorting hosts by MAC address, so you can arrange each view the way that suits it rather than sharing one global order ([#569](https://github.com/scanopy/scanopy/issues/569)).

  ![Container view with the sort order dropdown open showing Automatic and MAC address options](/changelog/v0.17.18/per-view-sort-order.png)

- Read configuration secrets from files via `SCANOPY_<NAME>_FILE`, making it easy to wire Scanopy up to Docker and Kubernetes secrets instead of plain environment variables.
- Trust your operator CA bundle for outbound connections, so Scanopy can reach services behind an internal certificate authority without TLS errors.

## Improvements

- Record every port a neighbour advertises for a far end, giving you a more complete and accurate picture of multi-port links in topology.
- Detect Cockpit, and correctly identify TrueNAS SCALE systems that don't expose SMB.
- Simplify the plan picker by grouping features into categories and dropping the "recommended" badges, making it easier to compare what each plan actually includes.
- Retry the alternate scheme after a failed HTTP probe, so web services are identified more reliably during discovery.
- Point you to email support directly from daemon troubleshooting, and clarify the standby error message.
- Name the specific untrusted certificate in errors, and keep event tokens out of logs.
- Update bundled dependencies to pick up the latest security fixes.

## Bug Fixes

- Fix a crash on Windows when the daemon starts without Npcap installed.
- Stop retried webhooks from sending duplicate emails, and accept Stripe webhooks regardless of the API version they were sent with.
- Treat all-zero MAC addresses as no MAC, and correctly merge MAC addresses discovered on a rescan so hosts no longer show bogus hardware addresses.
- Preserve server-provided ordering when paging through lists, instead of reshuffling results.
- Draw the preview edge in the dependency tutorial so the step is actually demonstrable.
