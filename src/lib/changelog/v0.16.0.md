This release is all about a more intuitive topology experience — from clearer dependency edges and entity-aware labels, to a refreshed visual style and smarter navigation in complex maps.

## New Features
- Overhaul topology visualization with entity-aware labels and improved dependency edge presentation, making complex networks easier to read and understand ([#552](https://github.com/scanopy/scanopy/pull/552), [#553](https://github.com/scanopy/scanopy/pull/553)).
  
  ![Topology view with entity-aware labeling and clearer dependency edges](/changelog/v0.16.0/entity-labels-topology.png)

- Introduce a smarter, minimap-aware fitView function that automatically frames your topology to avoid node overlap, even in large or collapsed layouts ([#567](https://github.com/scanopy/scanopy/pull/567)).
- Add view-agnostic search that highlights results in collapsed containers and navigates directly to matching nodes, speeding up exploration in big networks ([#566](https://github.com/scanopy/scanopy/pull/566)).
- Expand dependency builder with sentence-style cards, entity tagging, and edge type indicators, making application mapping more visual and interactive ([#561](https://github.com/scanopy/scanopy/pull/561), [#563](https://github.com/scanopy/scanopy/pull/563)).
  
  ![Application dependency builder with sentence cards and entity tags](/changelog/v0.16.0/dependency-builder-cards.png)

- Refresh icon and color palettes for the UI, offering a cleaner and more consistent look throughout the app ([#543](https://github.com/scanopy/scanopy/pull/543)).
  
## Improvements
- Refine share and embed views to use view-appropriate edge styles, collapse inspector panels by default, and center the switcher for easier access ([#558](https://github.com/scanopy/scanopy/pull/558), [#580](https://github.com/scanopy/scanopy/pull/580)).
- Improve sidebar layout with tighter navigation item padding and smaller icons for better use of screen space ([#577](https://github.com/scanopy/scanopy/pull/577)).
- Make InfoRow UI responsive, with flexible wrapping and visually distinct indentation for wrapped content ([#576](https://github.com/scanopy/scanopy/pull/576)).
- Cascade credential overrides and add a fallback to defaults, so scans work even with partial credential setup ([#544](https://github.com/scanopy/scanopy/pull/544)).

## Bug Fixes
- Fix Windows ARP discovery so interfaces are properly matched, resolving scan gaps on Windows hosts ([#530](https://github.com/scanopy/scanopy/pull/530)).
- Address duplicate interface entries and reconcile VLANs after rescan, ensuring network maps stay accurate ([#537](https://github.com/scanopy/scanopy/pull/537)).
- Fix share view availability scope and host modal dropdowns, so sharing works reliably across your networks ([#553](https://github.com/scanopy/scanopy/pull/553)).
- Repair selection and edge inspector bugs for clearer interaction in topology views ([#534](https://github.com/scanopy/scanopy/pull/534)).
- Resolve dependency edge grouping and inspector bugs in application maps, so all dependencies display and edit correctly ([#563](https://github.com/scanopy/scanopy/pull/563)).
