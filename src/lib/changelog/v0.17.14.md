This release is mostly about making better sense of what discovery finds: neighbouring devices now turn into real hosts on your map, service detection has to prove what answered, and scan warnings are grouped, deduplicated and actionable.

## New Features

- Add automatic hosts for LLDP/CDP neighbours nothing has scanned yet — each far end is resolved by the address and port it advertises, and the address space behind unplaceable neighbours is inferred so they still land somewhere sensible on the map ([#660](https://github.com/scanopy/scanopy/pull/660)).
- Rework scan warnings so they are grouped by what they ask of you, with duplicates merged, related warnings nested, severe items clearly marked, and the whole run copyable exactly as recorded ([#669](https://github.com/scanopy/scanopy/pull/669)).
- Add detection for H.323, TFTP, MGCP, Beszel and four industrial protocols, so more of your network is identified by name instead of by port number ([#673](https://github.com/scanopy/scanopy/pull/673)).
- Let a MAC address identify a host when it comes from a trustworthy source, and rank discovered values by where they came from so the most reliable reading wins ([#679](https://github.com/scanopy/scanopy/pull/679)).
- Let a real reading correct an assumed subnet range, and report every unconfirmed range rather than only newly seen ones ([#684](https://github.com/scanopy/scanopy/pull/684)).

## Improvements

- Speed up SNMP neighbour discovery by resolving all neighbours from a single read instead of one query per neighbour, and fall back to getnext for devices that stop answering getbulk ([#691](https://github.com/scanopy/scanopy/pull/691)).
- Simplify only the topology graphs that are big enough to need it, keep detail visible further out when zooming, and say clearly when detail stops being drawn ([#692](https://github.com/scanopy/scanopy/pull/692)).
- Apply field filters on the server for paginated entity tabs, so filtering large host and interface lists stays fast ([#693](https://github.com/scanopy/scanopy/pull/693)).
- Give hosts a consistent title everywhere, including hosts with no name, deleted hosts and collapsed containers, and badge hosts nothing has ever contacted ([#681](https://github.com/scanopy/scanopy/pull/681)).

## Bug Fixes

- Fix a blank topology canvas caused by a render that never finished, and make the view fit correctly on load ([#695](https://github.com/scanopy/scanopy/pull/695)).
- Fix a 422 error that could interrupt host discovery ([#666](https://github.com/scanopy/scanopy/pull/666)).
- Stop controller devices being filed under the internet instead of their own network ([#660](https://github.com/scanopy/scanopy/pull/660)).
- Fix entity tabs scrolling sideways into blank space ([#693](https://github.com/scanopy/scanopy/pull/693)).
- Stop a superseded dialog from closing the one that replaced it ([#681](https://github.com/scanopy/scanopy/pull/681)).
- Correct Oracle TNS detection so those services are recognised reliably ([#673](https://github.com/scanopy/scanopy/pull/673)).
