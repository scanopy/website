We're excited to share updates that make Scanopy even smoother to set up and easier to navigate. This release focuses on simplifying the discovery process and improving the clarity of network topology maps.

  • Onboarding in mixed environments is easier: Clearly labeled daemon types and socket-based credential support in the discovery picker streamline multi-platform setups.
  • Credential workflow is more direct: The discovery wizard now goes straight to credential selection, skipping unnecessary prompts for a faster experience.
  • Credential compatibility checks: UI automatically gates credentials based on detected daemon versions, preventing errors from incompatible selections.
  • Unified container bridge grouping: Topology grouping and container bridge merging now work across Docker, Podman, and other runtimes, making maps more accurate and less confusing.
  • Fixed L2 switch visibility: Network hardware switches now reliably appear in topology maps after rescans—no more missing devices.
