# Scanopy v0.13.6 Release Notes

## New Features

- Add internationalization (i18n) support using Paraglide JS, allowing Scanopy's interface to be translated into multiple languages for a more accessible user experience ([#441](https://github.com/scanopy/scanopy/pull/441), [#444](https://github.com/scanopy/scanopy/pull/444)).
- Introduce typed error codes throughout the app to provide clearer error messages, improving troubleshooting for users ([#441](https://github.com/scanopy/scanopy/pull/441), [#444](https://github.com/scanopy/scanopy/pull/444)).
- Add integration repository messaging to user API screens, keeping users informed about available integrations and updates ([#461](https://github.com/scanopy/scanopy/pull/461)).
- Introduce community translation workflow by scoping Weblate integration, enabling users to contribute translations directly
