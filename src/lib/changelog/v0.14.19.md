This release is all about making Scanopy simpler to get started with, and a lot more approachable for first-time users — with a new guided onboarding flow, improved mini topology previews, and streamlined discovery controls.

## New Features

- Add guided onboarding with a sidebar checklist, helpful empty states, and a simplified homepage so new users can get oriented and track setup progress ([#838](https://github.com/scanopy/scanopy/pull/838)).

  ![Screenshot of new onboarding checklist and homepage with empty state guidance](/changelog/v0.14.19/guided-onboarding.png)

- Replace the static network preview with an interactive mini topology featuring a scan sweep animation, service hover highlights, and smoother interactions to give a clearer, more engaging overview of your network ([#867](https://github.com/scanopy/scanopy/pull/867)).

  ![Animated mini topology network preview with interactive node cards and sweep effect](/changelog/v0.14.19/mini-topology.png)

- Add enable/disable toggle switches to scheduled discovery cards, letting you easily pause or resume recurring network scans directly from the dashboard ([#855](https://github.com/scanopy/scanopy/pull/855)).

- Add progressive host reporting during discovery so you can see detected devices appear in real-time as the scan progresses ([#879](https://github.com/scanopy/scanopy/pull/879)).

## Improvements

- Redesign and enhance the daemon installation and troubleshooting flows, including wider and more readable modals, clearer step-by-step prompts, and instant feedback on connection health to reduce confusion ([#846](https://github.com/scanopy/scanopy/pull/846), [#849](https://github.com/scanopy/scanopy/pull/849)).
- Overhaul onboarding empty states and sidebar UX for a smoother introduction to Scanopy features ([#869](https://github.com/scanopy/scanopy/pull/869)).
- Show all detected hosts in topology maps by default, and introduce tag-based filters for faster device navigation ([#884](https://github.com/scanopy/scanopy/pull/884)).
- Streamline troubleshooting links and UI, add external link indicators, and clean up message layout for a less cluttered experience ([#857](https://github.com/scanopy/scanopy/pull/857)).
- Clarify connection status and error messaging throughout the app, so it's easier to understand scan/daemon state and resolve issues ([#871](https://github.com/scanopy/scanopy/pull/871)).
- Make sidebar and homepage banners non-overlapping and less intrusive ([#875](https://github.com/scanopy/scanopy/pull/875)).
- Polish billing modals and referral prompts, making them visually consistent with the rest of the app ([#874](https://github.com/scanopy/scanopy/pull/874)).
- Auto-disable scheduled discoveries after repeated failures to prevent stuck jobs ([#893](https://github.com/scanopy/scanopy/pull/893)).

## Bug Fixes

- Fix scheduler deadlocks, discovery toggles, and cases where scheduled jobs could get stuck or not properly enable/disable ([#891](https://github.com/scanopy/scanopy/pull/891)).
- Fix UI issues in troubleshooting and daemon prompt modals, including text alignment and state persistence ([#845](https://github.com/scanopy/scanopy/pull/845), [#847](https://github.com/scanopy/scanopy/pull/847)).
- Fix duplicate/hidden hosts or categories in topology caused by tag filter bugs ([#895](https://github.com/scanopy/scanopy/pull/895)).
- Correct onboarding test feedback regressions and edge case empty state copy in discovery panel ([#882](https://github.com/scanopy/scanopy/pull/882)).
- Fix billing modal scroll layout and excess spacing issues ([#878](https://github.com/scanopy/scanopy/pull/878)).
- Make sure referral source selection updates correctly and is visible in all views ([#872](https://github.com/scanopy/scanopy/pull/872)).
