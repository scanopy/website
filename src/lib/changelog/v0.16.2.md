This release focuses on license management enhancements and improved reliability during database upgrades.

## New Features

- Add a 7-day license grace period, so you have extra time to resolve license issues before service is interrupted ([#592](https://github.com/scanopy/scanopy/pull/592)).

## Improvements

- Preserve device alias entries when performing database baseline operations, making network topology labels more resilient during upgrades ([#592](https://github.com/scanopy/scanopy/pull/592)).
- Add standard OCI labels to Docker images for better compatibility with registries and deployments ([#592](https://github.com/scanopy/scanopy/pull/592)).

## Bug Fixes

- Fix a rare race condition with deployment mode markers that could cause incorrect release event reporting ([#592](https://github.com/scanopy/scanopy/pull/592)).
