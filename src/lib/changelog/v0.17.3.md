This release focuses on smoother discovery setup and improved clarity for credential handling, with several important fixes for network topology display.

## New Features

- Allow socket-based credentials in the discovery picker and enforce daemon minimum version to ensure only supported credentials are sent to the daemon running the scan, making mixed-environment onboarding simpler ([#650](https://github.com/scanopy/scanopy/pull/650)).

## Improvements

- Generalize container bridge merging and topology grouping beyond Docker, so users running Podman or other runtimes see unified groups and links ([#653](https://github.com/scanopy/scanopy/pull/653)).
- Clarify copy and rule descriptions for topology grouping and container bridge merging, making network maps and groupings less confusing ([#653](https://github.com/scanopy/scanopy/pull/653)).

## Bug Fixes

- Fix L2 topology switches that could vanish after rescan, ensuring all hardware switches remain visible as expected ([#649](https://github.com/scanopy/scanopy/pull/649)).
- Scope daemon-host credential assignments to the loopback IP, preventing accidental leaking of credentials to other endpoints ([#650](https://github.com/scanopy/scanopy/pull/650)).
- Fix broken documentation anchors and add live testing to prevent future broken doc links ([#655](https://github.com/scanopy/scanopy/pull/655)).
