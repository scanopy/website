## New Features

- Add topology export formats, allowing users to download network maps as SVG images or as Mermaid and Confluence markup for easy documentation and sharing ([#494](https://github.com/scanopy/scanopy/pull/f7afda6c)).
- Add option to sort hosts by interface IP address, making it easier to locate and organize hosts in complex networks ([#492](https://github.com/scanopy/scanopy/pull/1a4e3c47)).
- Introduce SCANOPY_DISABLE_PASSWORD_LOGIN option to enforce OIDC-only authentication in deployments where password-based login should be disabled ([#487](https://github.com/scanopy/scanopy/pull/a59a3d62)).
- Auto-standby inactive daemons after 30 days, improving resource usage and network hygiene by pausing dormant agents automatically ([#507](https://github.com/scanopy/scanopy/pull/81ff910e), [#510](
