This release focuses on powerful topology filtering controls and improved sharing options, making it easier to manage large network maps and collaborate securely.

## New Features

- Add granular topology filtering, letting you control visibility for services, ports, and metadata directly from dedicated filter panels ([#170](https://github.com/scanopy/scanopy/pull/170), [#172](https://github.com/scanopy/scanopy/pull/172)).

  ![Topology filter panel with per-entity controls and hover states](/changelog/v0.16.1/topology-filters.png)

- Introduce enhanced share modal with password protection and access tokens, so you can grant secure, time-limited access to network maps ([#175](https://github.com/scanopy/scanopy/pull/175)).
- Default topology view to L3 with smart collapsed sections, giving you a clearer starting point when exploring larger environments ([#177](https://github.com/scanopy/scanopy/pull/177)).

## Improvements

- Improve inline filter interactions with persistent underlines, softer dividers, pulse indicators, and better hover feedback for a more intuitive experience ([#171](https://github.com/scanopy/scanopy/pull/171)).
- Update warning UI with darker light-mode text and clearer borders, making system alerts more visible ([#173](https://github.com/scanopy/scanopy/pull/173)).
- Change Host entity color from blue to amber for easier distinction between network components ([#174](https://github.com/scanopy/scanopy/pull/174)).
- Hide Free plan from billing modal for non-Free organizations, simplifying subscription management ([#176](https://github.com/scanopy/scanopy/pull/176)).
- Block organization deletion if an active paid subscription exists, preventing accidental loss of paid resources ([#178](https://github.com/scanopy/scanopy/pull/178)).
- Send confirmation email when an organization is deleted, providing clear account closure communication ([#178](https://github.com/scanopy/scanopy/pull/178)).

## Bug Fixes

- Fix node overlap in topology maps during live discovery updates, ensuring maps stay readable as new devices appear ([#179](https://github.com/scanopy/scanopy/pull/179)).
- Correct Revert logic for Create button visibility and billing routes for metered plans ([#180](https://github.com/scanopy/scanopy/pull/180)).
- Restore service element cards so service rows display consistently in topology views ([#181](https://github.com/scanopy/scanopy/pull/181)).
- Fix blank UI when accessing on plain HTTP, so the app loads properly in insecure environments ([#182](https://github.com/scanopy/scanopy/pull/182)).
- Fix collapsed container summary counts and remove redundant suffixes for accuracy on grouped topology entities ([#183](https://github.com/scanopy/scanopy/pull/183)).
