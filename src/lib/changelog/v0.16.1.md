This release focuses on powerful topology filtering controls and improved sharing options, making it easier to manage large network maps and collaborate securely.

## New Features

- Add granular topology filtering, letting you control visibility for services, ports, and metadata directly from dedicated filter panels ([#170](https://github.com/scanopy/scanopy/pull/170), [#172](https://github.com/scanopy/scanopy/pull/172)).

  ![Topology filter panel with per-entity controls and hover states](/changelog/v0.16.1/topology-filters.webp)

- Introduce enhanced share modal with token-based access, so you can grant secure, time-limited access to network maps ([#175](https://github.com/scanopy/scanopy/pull/175)).
- Default topology view to L3 with smart collapsed sections, giving you a clearer starting point when exploring larger environments ([#177](https://github.com/scanopy/scanopy/pull/177)).

## Improvements

- Send confirmation email when an organization is deleted, providing clear account closure communication ([#178](https://github.com/scanopy/scanopy/pull/178)).

## Bug Fixes

- Fix node overlap in topology maps during live discovery updates, ensuring maps stay readable as new devices appear ([#179](https://github.com/scanopy/scanopy/pull/179)).
- Fix blank UI when accessing on plain HTTP, so the app loads properly in insecure environments ([#182](https://github.com/scanopy/scanopy/pull/182)).
- Fix collapsed container summary counts and remove redundant suffixes for accuracy on grouped topology entities ([#183](https://github.com/scanopy/scanopy/pull/183)).
