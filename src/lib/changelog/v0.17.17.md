This release focuses on making long-running scans honest about what they're doing — with a new Issues tab, clear end-of-scan reasons, and a raft of fixes for runs that used to hang forever. It also brings invoice-based billing to self-hosted and air-gapped deployments.

## New Features

- Add an Issues tab that collects scan problems in one place, so you can see what went wrong without digging through the run history ([#694](https://github.com/scanopy/scanopy/pull/694)).

  ![Scan detail page with the new Issues tab listing discovery problems and degradation warnings](/changelog/v0.17.17/scan-issues-tab.png)

- Show why a scan ended and flag when a running scan stops reporting, so a stalled or degraded run is obvious at a glance instead of appearing to run indefinitely ([#694](https://github.com/scanopy/scanopy/pull/694)).
- Add one-click copying of a failed run's diagnostics, making it much faster to share details when you need help.
- Introduce invoice billing for self-hosted and air-gapped deployments, including a visible paid-through date on your license so you always know when coverage expires ([#694](https://github.com/scanopy/scanopy/pull/694)).

  ![License page showing invoice billing status and the paid-through date](/changelog/v0.17.17/invoice-billing-license.png)

- Replace plan downgrades with a clearer lapse-and-resume model: an unpaid license lapses with an explanatory email, and settling the invoice restores it automatically.

## Improvements

- Time out API requests the server never answers, so the interface no longer hangs waiting on a dead connection.
- Show a proper translated message when the server is unreachable, instead of a raw or untranslated error.
- Widen the self-hosted onboarding flow and clarify its wording to make first-time setup easier to follow.
- Report API errors consistently across the app so failures always surface with a usable explanation.
- Trim stray whitespace from typed email addresses and autofocus sign-in fields for faster logins.
- Reprice cloud plans and retire the Starter tier, simplifying the plan lineup.

## Bug Fixes

- Fix scans that could hang indefinitely by bounding waits in the discovery pipeline and adding a watchdog that cleans up sessions a daemon has lost or can no longer cancel ([#694](https://github.com/scanopy/scanopy/pull/694)).
- End discovery sessions whose daemon has disappeared, rather than leaving them stuck in a running state.
- Fix cancelled scans leaving behind probes and senders that kept running after you stopped the scan.
- Stop replayed scans correctly and prevent duplicate replays from being recorded.
- Fix newer daemons being misidentified as legacy versions, which could cause scans to use the wrong behaviour.
- Fix the Save button staying disabled after a valid selection was made.
