This release focuses on making long-running scans trustworthy — you can now see when a scan stalls, why it ended, and what went wrong — alongside a rework of billing and licensing that adds invoice-based plans for self-hosted and air-gapped deployments.

## New Features

- Add an Issues tab that collects everything that went wrong during a scan in one place, with a one-click copy of a failed run's diagnostics for support.

  ![Scan detail page showing the new Issues tab listing problems encountered during discovery](/changelog/v0.17.17/scan-issues-tab.png)

- Show why a scan ended — completed, cancelled, or failed — and warn you while it's running if it stops reporting progress or degrades, instead of leaving it spinning indefinitely.
- Introduce invoice billing and quotes for self-hosted plans, so organizations that can't pay by card can request a quote and be billed by invoice ([#694](https://github.com/scanopy/scanopy/pull/694)).

  ![License tab showing invoice billing option with quote request and invoice summary](/changelog/v0.17.17/invoice-billing.png)

- Add support for air-gapped license keys, including a key type switch, key rotation, and advance warnings before a key expires.

## Improvements

- Reprice cloud plans and retire Starter; organizations that lapse now keep their plan in a suspended state rather than silently dropping to Free, and settling an outstanding invoice restores the licence automatically.
- Let past-due organizations change plan instead of being locked out of billing entirely.
- Point every license banner at the License tab and consolidate the stack so you don't get multiple overlapping notices.
- Time out API requests the server never answers, and show a clear translated message when the server is unreachable instead of hanging.
- Widen self-hosted onboarding with clearer copy, trimmed email content, and autofocused sign-in fields.
- Send a scan its subnets up front, removing a round trip that could delay discovery starting.

## Bug Fixes

- Fix scans that could hang forever when a daemon disappeared, was busy, or refused a cancellation — sessions now fail cleanly and stop the daemon.
- Fix probes and senders continuing to run after a scan was cancelled.
- Fix newer daemons being misidentified as legacy versions.
- Fix the trial-ending warning appearing after the trial had already ended.
- Fix incorrect renewal dates and add a clear message when a card payment is declined.
