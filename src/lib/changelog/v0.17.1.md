This release is all about making credentials and agent setup simpler, more flexible, and easier to manage. We’ve also polished billing flows and improved how device interfaces appear in your topology.

## New Features
- Unify credentials and daemon setup into a single wizard, letting you add, name, and assign both network and host credentials with a streamlined  flow ([#641](https://github.com/scanopy/scanopy/pull/641)).
- Introduce assignment controls for credentials, letting you pick exactly which hosts or networks each credential applies to, and see live assignment changes as you edit ([#641](https://github.com/scanopy/scanopy/pull/641)).
- Enforce single-endpoint-per-host for Docker-style integrations, protecting against accidental configuration conflicts ([#642](https://github.com/scanopy/scanopy/pull/642)).
- Require payment card directly in the plan modal, integrating a themed Stripe Payment Element for simpler billing and signup ([#644](https://github.com/scanopy/scanopy/pull/644)).
  
  ![Stripe card modal with organization plan selection and payment field](/changelog/v0.17.1/stripe-card-modal.png)

## Improvements
- Improve device interface deduplication in topology, so ports without IPs now show correctly and won’t collapse together ([#641](https://github.com/scanopy/scanopy/pull/641)).
- Streamline billing and plan selection flows, with clearer CTAs, usage details, and in-app card modal nudges ([#644](https://github.com/scanopy/scanopy/pull/644)).
- Add DNS deliverability check during signup to help ensure your organization receives important emails ([#644](https://github.com/scanopy/scanopy/pull/644)).

## Bug Fixes
- Fix wizard validation toast messages to name the exact field or credential that needs attention, making errors easier to resolve ([#641](https://github.com/scanopy/scanopy/pull/641)).
