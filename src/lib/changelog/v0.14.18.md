## New Features

- Add multi-select for topology view, enabling users to efficiently select and manage multiple entities at once ([#502](https://github.com/scanopy/scanopy/pull/502)).

![Topology viewer with multi-select](/changelog/v0.14.18/topology-multi-select.png)

- Add discovery time estimation with documentation link for longer-running sessions during longer operations ([#533](https://github.com/scanopy/scanopy/pull/533)).
  
![Discovery progress indicator showing scan phases and completion status](/changelog/v0.14.18/discovery-progress.png)

- Add discovery progress indicator to topology tab, providing real-time feedback on each discovery phase and completion status ([#530](https://github.com/scanopy/scanopy/pull/530)).

![Topology discovery indicator](/changelog/v0.14.18/topology-discovery-progress.png)

- Add topology search (ctrl/cmd + /) and keyboard shortcuts (shift + ?), enabling faster navigation and discovery of entities within large network maps ([#522](https://github.com/scanopy/scanopy/pull/522)).

![Topology keyboard shortcuts](/changelog/v0.14.18/keyboard-shortcuts.png)


## Improvements

- Improve inspect panel with port listings, category tags, and enhanced tag pickers for richer and more actionable entity insights ([#516](https://github.com/scanopy/scanopy/pull/516)).
- Refine topology controls by using a unified panel layout, streamlining user actions for zoom, keyboard shortcuts, and navigation ([#522](https://github.com/scanopy/scanopy/pull/522)).
- Highlight new nodes after topology rebuild, helping users quickly identify recent additions to their network map ([#529](https://github.com/scanopy/scanopy/pull/529)).
- Add phase-specific hints during discovery, moving hints above progress bar to provide context-aware guidance ([#533](https://github.com/scanopy/scanopy/pull/533)).
- Hide advanced topology controls before first rebuild to reduce onboarding confusion ([#529](https://github.com/scanopy/scanopy/pull/529)).
- Add compile-time guard against permission upgrades, reinforcing security and user roles ([#510](https://github.com/scanopy/scanopy/pull/510)).
- Unify checkbox toggles in inspectors for consistent interaction design ([#502](https://github.com/scanopy/scanopy/pull/502)).

## Bug Fixes

- Fix discovery host limit bypass, ensuring user-configured limits are enforced during scans ([#514](https://github.com/scanopy/scanopy/pull/514)).
- Fix entity tag navigation for unfetched entities, resolving sporadic errors during card interactions ([#515](https://github.com/scanopy/scanopy/pull/515)).
- Fix RefreshConflictsModal missing filtered entities for improved conflict resolution feedback ([#534](https://github.com/scanopy/scanopy/pull/534)).
- Fix daemon retry logic on billing limit errors, ensuring robustness during edge cases ([#514](https://github.com/scanopy/scanopy/pull/514)).
- Guard billing email handlers against Free plan and missing payment method, preventing unwanted prompts ([#534](https://github.com/scanopy/scanopy/pull/534)).
- Stop creating Free subscription in Stripe on downgrade, avoiding unnecessary billing change events ([#530](https://github.com/scanopy/scanopy/pull/530)).
