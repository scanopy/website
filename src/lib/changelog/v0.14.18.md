## New Features

- Add minimap to topology viewer, allowing quick navigation and spatial understanding of large network maps ([#529](https://github.com/scanopy/scanopy/pull/529)).

  ![Topology viewer with minimap for easier navigation](/changelog/v0.14.18/topology-minimap.png)

- Add multi-select for topology view, enabling users to efficiently select, inspect, and manage multiple entities at once ([#502](https://github.com/scanopy/scanopy/pull/502)).

- Add discovery progress indicator to topology tab, providing real-time feedback on each discovery phase and completion status ([#530](https://github.com/scanopy/scanopy/pull/530)).

  ![Discovery progress indicator showing scan phases and completion status](/changelog/v0.14.18/discovery-progress.png)

- Add topology summary stats bar, summarizing host, device, service, and subnet counts at a glance for improved situational awareness ([#534](https://github.com/scanopy/scanopy/pull/534)).

  ![Stats bar in panel header showing entity counts](/changelog/v0.14.18/topology-stats-bar.png)

- Add topology search, keyboard shortcuts, and zoom-to-fit, enabling faster navigation and discovery of entities within large network maps ([#522](https://github.com/scanopy/scanopy/pull/522)).

- Add subnet tag picker and reorder tags above description for improved tagging and organization of subnets ([#515](https://github.com/scanopy/scanopy/pull/515)).

- Add discovery time estimation and waiting suggestions, helping users understand scan duration and receive relevant nudges during longer operations ([#533](https://github.com/scanopy/scanopy/pull/533)).
