## New Features

- Add SNMP discovery support and expand SNMP credential handling, enabling richer network asset identification via SNMP and flexible credential management ([#469](https://github.com/scanopy/scanopy/pull/469)).
- Implement ServerPoll daemon mode specifically for DMZ deployments, supporting new network architectures ([#465](https://github.com/scanopy/scanopy/pull/465)).
- Add lightweight topology update endpoints, allowing faster incremental updates for improved performance and up-to-date network views ([#468](https://github.com/scanopy/scanopy/pull/468)).
- Add scan rate limiting and adaptive batch sizing, reducing the risk of resource exhaustion and providing smoother operation even in large networks ([#468](https://github.com/scanopy/scanopy/pull/468)).
- Add CSV export functionality to UI tab pages and backend endpoints for all entities, enabling easy export and sharing of network, host, and service
