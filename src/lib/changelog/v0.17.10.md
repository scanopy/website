This release focuses on more accurate SNMP-based topology discovery, plus the UniFi integration graduating to general availability.

## New Features

- Promote the UniFi integration to general availability, so you can rely on it for production network discovery without opting into a preview ([#675](https://github.com/scanopy/scanopy/pull/675)).
- Add Czech as a supported language, and refresh the Tamil and Simplified Chinese translations.

## Improvements

- Read SNMP bridge tables that devices return out of order, so switches with non-standard SNMP agents now contribute complete link data to your topology ([#675](https://github.com/scanopy/scanopy/pull/675)).

## Bug Fixes

- Fix links being drawn to an arbitrary port when several ports on a switch share the same MAC address, which previously produced misleading connections in the topology view ([#675](https://github.com/scanopy/scanopy/pull/675)).
- Fix subnets appearing or disappearing incorrectly in the topology by deciding visibility based on how a subnet was discovered rather than how it was categorized ([#675](https://github.com/scanopy/scanopy/pull/675)).
