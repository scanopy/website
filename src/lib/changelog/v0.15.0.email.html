We’re excited to announce new Scanopy updates that make network discovery faster, easier, and more reliable. This release delivers powerful scanning options and improved credential workflows designed for busy network admins.

  • Run quicker scans when needed — Light scan mode lets you get fast network visibility with minimal probing, ideal for routine checks or quick topology views.
  • Discover remote Docker containers — Scan containers on hosts across your network without needing local access, streamlining container inventory and mapping.
  • Assign credentials on the fly — Manage and update credentials directly within the discovery modal, speeding up scan setup and improving workflow efficiency.
  • Disable unnecessary deep scans — More control with flexible scheduling, so you only run full scans when they’re needed for your environment.
  • Accurate loopback and host mapping — Improved logic ensures loopback-connected hosts and subnets are properly discovered and visualized, eliminating confusion and duplicate entries.

Thanks for helping us make Scanopy smarter and more intuitive for your network! Enjoy the new workflow enhancements and reliability improvements.
