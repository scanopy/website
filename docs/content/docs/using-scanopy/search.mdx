title: Search

Search finds hosts, services, subnets, and VLANs across every site you can access. Open it with <kbd>⌘</kbd> <kbd>K</kbd> on macOS or <kbd>Ctrl</kbd> <kbd>K</kbd> elsewhere, from any page, or click the search bar at the top of the sidebar.

## What each entity matches on

Matching is case-insensitive and finds the text anywhere in a field.

| Entity  | Matches on                                                                                                           |
| ------- | -------------------------------------------------------------------------------------------------------------------- |
| Host    | name, hostname, sysName, chassis ID, serial number, [asset tag](/using-scanopy/network-data/#asset-tags), description, IP addresses, MAC addresses, names of its services |
| Service | name, service type, name of its host                                                                                 |
| Subnet  | name, CIDR, description                                                                                              |
| VLAN    | VLAN number, name, description                                                                                       |

Results are grouped by entity type, up to five of each. Use <kbd>↑</kbd> and <kbd>↓</kbd> to move and <kbd>Enter</kbd> to open a result. A host, service, or subnet opens in its editor. A VLAN opens the VLAN list.

## Search compared with topology search

| | Search | Topology search |
| --- | --- | --- |
| Shortcut | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>K</kbd>, on any page | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>F</kbd>, on the topology |
| Finds | Hosts, services, subnets, and VLANs on every site you can access | Elements drawn on the topology you're viewing |
| Result | Opens the entity | Highlights the matches on the canvas and steps through them |

<kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>K</kbd> opens search on the topology too.
