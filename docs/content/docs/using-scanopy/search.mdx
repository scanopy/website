---
title: Search
description: Searching every site you can access, filtering the list you're on, and finding elements on the topology.
---

Scanopy has three searches, each named by what it does:

| | Search all | Filter a list | Find on the topology |
| --- | --- | --- | --- |
| Shortcut | <kbd>/</kbd>, on any page | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>F</kbd>, on a list page | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>F</kbd>, on the topology |
| Covers | Every entity you can open, on every site you can access, by text or tag | The rows of the list you're viewing | Elements drawn in the topology view you're viewing |
| Result | Opens the entity | Narrows the list | Highlights matches and moves to them; <kbd>Enter</kbd> selects one |

## Search all

Press <kbd>/</kbd> from any page, or click **Search all** at the top of the sidebar. Matching is case-insensitive and finds the text anywhere in a field.

| Entity       | Matches on                                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| Site         | name                                                                                                                 |
| VLAN         | VLAN number, name, description                                                                                       |
| Subnet       | name, CIDR, description                                                                                              |
| Host         | name, hostname, sysName, chassis ID, serial number, [asset tag](/using-scanopy/network-data/#asset-tags), description, IP addresses, MAC addresses, names of its services |
| Service      | name, service type, name of its host                                                                                 |
| Discovery    | name, name of its daemon                                                                                             |
| Daemon       | name, URL                                                                                                            |
| Tag          | name, description                                                                                                    |
| User         | email; admins and owners only, and only the users the **Users** page shows them                                      |
| User API key | name; only your own keys                                                                                             |
| Credential   | name, description                                                                                                    |

Sections appear in this order: assets first, then discovery, then platform-wide entities, the same order as the sidebar.

A host's IP addresses, interfaces, ports and bindings have no results of their own: search for the address or MAC and the host comes up.

Results are grouped by entity type under a count of all matches. Each section shows its first five matches and how many there are in all; **Show more** at the end of a section loads up to 20 more. Use <kbd>↑</kbd> and <kbd>↓</kbd> to move and <kbd>Enter</kbd> to open a result or load more. A result opens in its editor; **Back to Search** in that editor reopens search with the same text and tags.

### Search by tag

When what you type starts the name of a tag, the tag appears faintly after your text. Press <kbd>Tab</kbd>, or click it, to add it as a tag in the search box. Results are then the entities carrying that tag, and any text you type narrows them.

- Add more tags the same way, or click a tag shown on a result. Results carry every tag in the box.
- Click a tag's **×** to remove it, or press <kbd>Backspace</kbd> in an empty box to remove the last one.
- With several tags in the box, press <kbd>←</kbd> at the start of your text to select the last tag, move between tags with <kbd>←</kbd> and <kbd>→</kbd>, and press <kbd>Backspace</kbd> to remove the selected one.
- When several tags start with what you typed, the one whose name matches it exactly is offered first, then the shortest name.
- Without a tag showing, <kbd>Tab</kbd> and <kbd>Esc</kbd> work as usual.

Every taggable entity can be found by its tags: hosts, services, subnets, VLANs, sites, daemons, discoveries, credentials and user API keys.

## Filter a list

Every list page has a filter box above the table. Press <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>F</kbd> to jump to it. It narrows the rows on screen to those matching your text. Column filters and grouping, set from the column headers, show beside the item count with a **Clear** button each.

## Find on the topology

On the topology, <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>F</kbd> finds elements in the current view. The placeholder lists what that view draws, such as subnets, IP addresses, ports, and services in L3 Logical. Use <kbd>↑</kbd> and <kbd>↓</kbd> to move between matches and <kbd>Enter</kbd> to select one.
