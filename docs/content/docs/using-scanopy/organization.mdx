## Organizations

Organizations are the top-level container in Scanopy. Every user belongs to exactly one organization, and all sites, hosts, and services exist within that organization.

Organizations are automatically created during registration and cannot be manually created or transferred.

### Roles

<RolesTable />

Account creation is invite-only — there is no self-registration. Invite users via **Platform > Users** — generate an invite link, select the invitee's role and which sites they may access, and share the link or send it by email.

Removing a user revokes all of their API keys, pending invitations, and site access grants.

## Sites

Sites are the locations your network runs in, such as an office or a data center. Each site holds its own hosts, services and topology. Open a site from **Assets > Sites** to edit its name, type, and its **Consider entities stale after** window (see [Staleness](/using-scanopy/staleness/#the-staleness-window)).

### Site Access

Users can be restricted to specific sites within an organization. When inviting a user, select which sites they may access — all data queries are filtered to those sites.

## Credentials

Credentials are organization-scoped: managed under **Platform > Credentials**, and assignable to any site or host in the organization. See [Credentials](/using-scanopy/credentials/) for types, targets, and assignment.

## API Keys

Create API keys for programmatic access in **Platform > API Keys**. See the [API reference](/api/).
