The Application perspective shows your services grouped by application, with explicit dependencies as the connections between them. Generic infrastructure services such as SSH, NTP and DHCP are hidden by default.

## What you see

- **Containers**: Application groups — one per application tag you've defined
- **Nodes**: Services that belong to those applications
- **Connections**: [Dependencies](/using-scanopy/dependencies) — request paths and hub-and-spoke relationships

## What drives it

Application groups are tags in the built-in [Application tag group](/using-scanopy/tags/#application-tags). A service joins a group either through its own tag or by inheriting from its host's tag. Connections come from dependencies you've created between services.

Services that don't belong to any application group are collected in an **Ungrouped** container.

See also: [Dependencies](/using-scanopy/dependencies), [Customizing Views](/using-scanopy/topology/customizing-views).
